# BooksApi

[فارسی](README.fa.md)

A simple ASP.NET Core Web API for managing books, built with C#, .NET 10, EF Core and SQLite.

## Features

- Full CRUD operations for books
- Data persistence with EF Core and SQLite
- Input validation with Data Annotations
- Async service layer and controller
- Ready-to-use `.http` file for testing requests

## Tech Stack

- C# / .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite

## Endpoints

| Method | URL              | Description      |
|--------|------------------|------------------|
| GET    | `/api/book`      | Get all books    |
| GET    | `/api/book/{id}` | Get a book by id |
| POST   | `/api/book`      | Add a new book   |
| PUT    | `/api/book/{id}` | Update a book    |
| DELETE | `/api/book/{id}` | Delete a book    |

## Book Model

| Field           | Type     | Rules                                      |
|-----------------|----------|--------------------------------------------|
| `id`            | int      | Generated by the database                  |
| `title`         | string   | Required                                   |
| `author`        | string   | Required                                   |
| `publishedDate` | DateTime | Format `yyyy-MM-dd`, between 1000 and 2100 |

## Getting Started

1. Clone the repository:
   ```
   git clone <your-repo-url>
   ```
2. Open the solution in Visual Studio (or use the terminal).
3. Create the database:
   ```
   dotnet ef database update
   ```
   (or run `Update-Database` in the Package Manager Console)
4. Run the project:
   ```
   dotnet run
   ```
5. Test the API with the requests in the `.http` file.

## Example Request

```http
POST /api/book
Content-Type: application/json

{
  "title": "Clean Code",
  "author": "Robert Martin",
  "publishedDate": "2020-02-05"
}
```

## Validation Example

An invalid request (empty title and a date out of range) returns `400 Bad Request` with a list of errors:

```json
{
  "title": "",
  "author": "Robert Martin",
  "publishedDate": "3000-01-01"
}
```
